# Review And Artifacts

Use this folder for review reports, screenshots, generated outputs, and test
artifacts.

## Contents

- `review-output/`: system and layout review reports and screenshots.
- `prototype-test-artifacts/`: prototype screenshots and UI test artifacts.
- `outputs/`: local generated artifacts; ignored unless explicitly promoted.
- `test-output-*.log`: historical test logs.

## Notes

Do not treat generated artifacts as product truth unless a handoff or report
explicitly promotes them.
